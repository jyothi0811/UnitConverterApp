# Unit Converter App

A simple Android Unit Converter application built using Kotlin and Jetpack Compose.

## Features

- Convert Meters to Kilometers
- Convert Kilograms to Pounds
- Convert Celsius to Fahrenheit
- User-friendly interface
- Input validation
- Real-time conversion result display

## Technologies Used

- Kotlin
- Jetpack Compose
- Android Studio

## How to Run

1. Clone the repository
2. Open in Android Studio
3. Sync Gradle files
4. Run the app on Emulator or Android Device

## Project Structure

- MainActivity.kt → Main application logic
- Jetpack Compose UI components
- Conversion logic implementation
